========================================================================
PANDUAN DEPLOY MANDIRI NGALAM FIX PRO KE CPANEL RUMAHWEB
========================================================================

Aplikasi ini sudah 100% siap dijalankan mandiri di Rumahweb.
Ikuti 5 langkah mudah berikut di cPanel Rumahweb Anda:

------------------------------------------------------------------------
LANGKAH 1: BUAT DATABASE MYSQL DI CPANEL
------------------------------------------------------------------------
1. Buka cPanel Rumahweb -> cari dan klik menu "MySQL® Database Wizard".
2. Masukkan nama database, contoh: "ngalamdb" (hasil akhir: cpaneluser_ngalamdb). Klik Next.
3. Buat user database, contoh: "ngalamuser" dan buat Password yang kuat. Catat password ini!
4. Klik Next -> Centang "ALL PRIVILEGES" (Semua Hak Akses) -> Klik Make Changes.
5. Kembali ke Beranda cPanel -> buka menu "phpMyAdmin".
6. Klik nama database yang baru dibuat di panel kiri (cpaneluser_ngalamdb).
7. Klik tab "Import" di bagian atas -> klik "Choose File" -> pilih file:
   "scripts/schema_mysql.sql" yang ada di dalam paket zip ini.
8. Klik tombol "Go" / "Kirim" di bagian bawah. Database dan semua tabel sudah siap!

------------------------------------------------------------------------
LANGKAH 2: UPLOAD & EKSTRAK FILE DI FILE MANAGER
------------------------------------------------------------------------
1. Di cPanel, buka menu "File Manager".
2. Buat folder baru di luar public_html atau di root direktori Anda, misalnya:
   /home/cpaneluser/ngalam-app/
   (Catatan: Jangan taruh backend Node.js langsung di dalam public_html biasa agar aman).
3. Masuk ke folder tersebut, klik tombol "Upload", lalu upload file:
   "NGALAM_FIX_PRO_RUMAHWEB.zip"
4. Setelah 100% selesai (warna hijau), klik kanan file zip tersebut -> pilih "Extract".
5. File dan folder aplikasi akan otomatis terekstrak rapi di folder tersebut.

------------------------------------------------------------------------
LANGKAH 3: ATUR FILE KONFIGURASI (.env)
------------------------------------------------------------------------
1. Di dalam folder aplikasi di File Manager, temukan file bernama ".env.example".
2. Klik kanan file ".env.example" -> pilih "Rename" -> ganti namanya menjadi:
   .env
   (Jika file tersembunyi tidak muncul, klik menu "Settings" di pojok kanan atas File Manager, centang "Show Hidden Files (dotfiles)").
3. Klik kanan file ".env" -> pilih "Edit":
   Sesuaikan bagian database MySQL sesuai data di Langkah 1:

   DB_DIALECT=mysql
   DB_HOST=localhost
   DB_PORT=3306
   DB_NAME=cpaneluser_ngalamdb
   DB_USER=cpaneluser_ngalamuser
   DB_PASSWORD=password_database_anda

   BASE_URL=https://domainanda.com
   NODE_ENV=production

4. Klik "Save Changes".

------------------------------------------------------------------------
LANGKAH 4: SETUP APLIKASI DI "SETUP NODE.JS APP"
------------------------------------------------------------------------
1. Di cPanel, cari dan klik menu "Setup Node.js App".
2. Klik tombol "Create Application" di pojok kanan atas.
3. Isi form berikut:
   - Node.js Version    : Pilih versi 18.x atau 20.x
   - Application Mode   : Production
   - Application root   : ngalam-app (sesuai nama folder di Langkah 2)
   - Application URL    : domainanda.com (atau subdomain jika pakai subdomain)
   - Application startup file : server.js
4. Klik tombol "CREATE" di pojok kanan atas.
5. Setelah aplikasi terbuat, di bagian "Configuration files" atau "Detected configuration",
   klik tombol "Run NPM Install" (cPanel akan menginstall dependency dalam 1-2 menit).
6. Di bagian atas, klik tombol "START APP" atau "RESTART".

------------------------------------------------------------------------
LANGKAH 5: SELESAI & UJI COBA
------------------------------------------------------------------------
Buka domain Anda di browser:
- Halaman Utama: https://domainanda.com
- Dashboard Admin: https://domainanda.com/admin
- 100 QR Code Mitra: https://domainanda.com/qrcodes/mitra/MITRA-001.png
- Download Semua QR Mitra: Langsung dari tab "Mitra Driver" di Dashboard Admin.

Selamat! Website dan sistem antrean Ngalam Fix Pro sudah 100% online di Rumahweb!
